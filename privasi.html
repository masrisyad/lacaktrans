Kebijakan Privasi

Berlaku sejak 30 Oktober 2026 · Aplikasi: LacakTrans (Android com.silsilara.lacaktrans dan web)

Kebijakan ini menjelaskan data apa yang dipakai LacakTrans, untuk apa, dan di mana data itu disimpan. Singkatnya: tanpa akun. Favorit dan setelan hanya di perangkat Anda. Lokasi dibaca untuk mencari halte terdekat dan tidak pernah dikirim ke server mana pun, karena LacakTrans tidak punya server untuk data pengguna.

1. Lokasi

Bila Anda mengizinkan, LacakTrans membaca lokasi perangkat untuk menampilkan halte dan stasiun terdekat dan untuk memusatkan peta ke posisi Anda. Lokasi hanya dipakai di perangkat saat aplikasi terbuka: tidak disimpan, tidak dikirim ke server LacakTrans, dan tidak diteruskan ke pihak lain. Tanpa izin lokasi, aplikasi tetap bisa dipakai dan halte terdekat dihitung dari tengah peta.

2. Data yang tersimpan di perangkat

  • Halte dan stasiun favorit.
  • Setelan: tema terang/gelap, bahasa, dan filter moda di peta.
  • Data jadwal terbaru yang diunduh dari situs LacakTrans, agar tetap bisa dipakai saat offline.
  • Kode acak statistik pemakaian (lihat bagian 4) dan penanda pemberitahuan versi baru yang ditunda.
  • Di Android: gambar kartu Story sementara saat Anda membagikannya; gambar lama dihapus saat Anda berbagi lagi.

Data ini tidak pernah dikirim ke server LacakTrans.

3. Layanan yang diakses langsung dari perangkat

Untuk menampilkan peta dan posisi kendaraan, aplikasi mengambil data langsung dari penyedianya:

  • Feed armada TransJakarta: posisi bus untuk area peta yang sedang terlihat. Server TransJakarta menerima permintaan per area peta, bukan lokasi GPS Anda.
  • OpenFreeMap: gambar peta (tile) untuk area yang sedang dilihat.
  • Situs LacakTrans (Vercel): jadwal terbaru, info versi, dan banner gangguan.

Seperti semua layanan internet, penyedia tersebut dapat melihat alamat IP perangkat yang meminta data. Google Maps, WhatsApp, Instagram, TikTok, Facebook, dan aplikasi lain hanya dibuka bila Anda mengetuk tombol bagikan atau "Rute ke sini", dan tunduk pada kebijakan privasi masing-masing.

4. Statistik pemakaian

Statistik pemakaian anonim (layar yang dibuka, fitur yang dipakai) dikirim ke PostHog (server di Uni Eropa) tanpa identitas dan tanpa lokasi GPS, untuk memprioritaskan pengembangan. Statistik ini memakai kode acak di perangkat, bukan akun, nama, atau nomor telepon.

5. Berbagi data

LacakTrans tidak menjual, menyewakan, atau membagikan data Anda kepada pihak ketiga, dan tidak memakai iklan. Penyedia layanan yang dipakai untuk menjalankan LacakTrans hanya memproses data untuk keperluan itu: Vercel (situs dan data jadwal), PostHog (statistik pemakaian), Google Drive (berkas APK), TransJakarta (posisi bus), dan OpenFreeMap (peta). Penyedia ini dapat memproses data di luar Indonesia.

6. Keamanan

Semua komunikasi aplikasi memakai koneksi terenkripsi (HTTPS dan WSS). Tidak ada akun atau kata sandi yang perlu dijaga karena LacakTrans tidak memakai akun.

7. Menghapus data

  • Hapus favorit satu per satu dari layar halte atau stasiun.
  • Hapus semua data di perangkat lewat Setelan Android → Aplikasi → LacakTrans → Penyimpanan → Hapus data, dengan menghapus aplikasi, atau dengan menghapus data situs di browser untuk versi web.
  • Cabut izin lokasi kapan saja di setelan HP atau browser.

8. Anak-anak

LacakTrans tidak meminta data pribadi dan bisa dipakai tanpa akun oleh siapa pun. Kami tidak dengan sengaja mengumpulkan data pribadi anak-anak.

9. Perubahan kebijakan

Bila kebijakan ini berubah, versi terbaru dan tanggal berlakunya akan diperbarui di halaman ini.
